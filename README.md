# My Quarto weibite

This repository contains the source code about the frequency of (non)official languages used in different situations in Canadam and the results of some mean value
in different given column's situations to explore the most-used languages of them.


# Installation

- R 4.6.1
- Git 2.50.1
- Quarto 1.10.18
- uv 0.12.7

The R package dependencies are managed using `renv`.
